# Security policy

`env-drift` reads source files and your example file to collect variable *names*. It never opens `.env`, never prints values, runs no code from your project, and makes no network requests.

If you find a security problem, please report it privately through [GitHub's private vulnerability reporting](https://github.com/nicoleyangcoding/env-drift/security/advisories/new) rather than opening a public issue. You can expect a reply within 7 days.
